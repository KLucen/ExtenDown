# ExtenDown 编辑体验调研与优化路线

2026-11-26 · 以 P4 完成后的 `9a91927` 为基线。对照产品选取 Typora、Obsidian 和 VS Code，分别覆盖排版后直接编辑、本地文档与插件管理、源码写作与导航。竞品功能依据公开文档，ExtenDown 依据当前代码、已有验收和文末列出的复现样例。

## 产品对照

| 产品 | 已核对的能力 | ExtenDown 可采取的设计 |
| --- | --- | --- |
| Typora | 排版后直接写作，文件树和文档大纲，表格插入、对齐、行列移动，分平台快捷键 | 让正文可以就地编辑，为复杂块提供就近的编辑入口。为文件行和正文分别提供适合当前对象的操作。[产品说明](https://typora.io/) · [文件管理](https://support.typora.io/File-Management/) · [表格编辑](https://support.typora.io/Table-Editing/) · [快捷键](https://support.typora.io/Shortcut-Keys/) |

## ExtenDown 当前缺口

| 能力 | 现状 | 优化重点 |
| --- | --- | --- |
| 基础语法 | CommonMark、GFM 表格和任务列表已渲染，识别 YAML frontmatter。任务复选框只读。GFM 脚注已解析，预览和离线 HTML 的脚注正文丢失 | 先补齐脚注编号、正文、跳转和返回，为勾选任务提供可撤销操作。为 frontmatter 提供明确的折叠区或源码入口 |
| 公式与 Mermaid | 可选 KaTeX MathML 和 Mermaid 已离线渲染，也参与导出。关闭扩展时，行内公式和 Mermaid 缺少对应的启用提示 | 提供行内／块级公式、矩阵和图表模板。图表卡片支持编辑源码、复制和放大。正常区分扩展停用、未安装、语法错误和到达渲染限制 |
| 高亮 | 预览有基础代码语言和可选额外语言包，源码编辑目前未加载 Markdown 语言着色 | 核心加入 Markdown 着色、代码围栏语言建议和列表续写。代码块增加复制、显示语言名和按需折叠。额外语言继续作为官方包 |
| 表格 | 预览可横向滚动，投影保留左、中、右列对齐。离线 HTML 构建时丢失对齐，界面缺少单元格和行列编辑 | 修复预览与导出对齐。核心提供插入表格、编辑单元格、增删行列及对齐。后续再评估排序和从 TSV 粘贴 |
| 编辑与导航 | 分屏和预览共享文档缓冲区。源码支持撤销与查找下一处，菜单、快捷键和预览未接通已有的选区变换能力。标题大纲可跳至源码 | 统一命令、快捷键、选区菜单和查找替换。再接入预览就地编辑、预览全文查找和源码／预览定位 |
| 文件与资源 | 已有打开、保存、多窗口、最近文件和草稿恢复。文档大纲只列当前标题，应用缺少工作区文件树 | 增加按需打开的文件树、快速找文件、在系统中显示和本地资源插入。跨文件全文搜索、重命名及链接更新分阶段交付 |
| 插件发现 | NSIS 支持八组选装扩展。应用内已有开关、主题包与第三方命令分区，缺少用途筛选、搜索和一致的状态说明 | 用同一官方组件目录驱动安装、首次启动和设置，保留现有选择和组件 ID |
| 导出 | HTML、位图分页 PDF、PNG 和 JPG 已验收，长图支持分段 ZIP | 先对齐脚注、表格和分页效果。后续增加保留可选中、可搜索文本的 PDF，继续提供现有位图输出 |

实测最小样例为 `正文[^note]` 搭配 `[^note]: 脚注内容。`。当前渲染投影保留引用数字，将脚注区显示为 HTML 占位符，HTML 也丢失脚注正文。另用 `| :-- | :-: | --: |` 确认表格投影保留三种对齐，但导出序列化丢弃了对齐属性。修复时应在受控 Markdown 变换中生成脚注锚点和列对齐，继续通过现有 HTML 清洗。[预览入口](../src/renderer/markdown-preview.tsx) · [预览投影](../src/core/preview-projection.ts) · [HTML 导出](../src/core/export/html-export.ts)

## 交互设计

### 视图与预览内编辑

左侧视图栏继续使用「源码／并排／预览」。预览默认用于阅读，在预览区右上进入「编辑正文」。进入后，可编辑的段落和标题在鼠标悬停或键盘聚焦时显示细边框和光标，双击或按 Enter 开始编辑。初版覆盖可准确映射到 Markdown 的普通段落和标题。公式、Mermaid、代码围栏和复杂表格通过块旁的「编辑源码」或表格面板处理。只读文件或当前无法映射的区域给出具体原因。

沿用 MerMarkd 的 `ReaderEditableBlock`、输入法会话和源位置映射。编辑以文档身份、草稿修订和原始片段校验提交，把最小差异作为一次 CodeMirror 事务写入。预览延迟刷新时重新校验最新草稿。切换视图、保存、导出和关闭窗口须等组合输入完成。写入沿用 BOM、CRLF、草稿恢复和磁盘冲突保护。[已有编辑块](../src/renderer/reader-editable-block.tsx) · [源位置映射](../src/core/reader-edit.ts) · [文档会话](../src/demo/document-session.ts)

### 正文选区与文件行

- **正文选区**用一条贴近选区的小工具条呈现「粗体、斜体、链接、更多」。右键菜单使用纵向文字命令，第一组为剪切、复制、粘贴为纯文本，第二组为「格式」「段落」「插入」。在表格或围栏中右键时，显示对应的块操作。用 Escape 关闭，关闭后恢复焦点和选区。
- **文件行**使用行末 `⋯` 或右键打开菜单。首批提供打开、在新窗口打开、复制相对路径、在资源管理器中显示。工作区写操作通过第二批加入，包括新建、重命名和移到回收站。两个菜单都支持 `Shift+F10`，键盘可以完成全部操作。

截图用作 Typora 文本右键操作的能力参考。ExtenDown 的组合使用正文工具条、纵向文字菜单和文件行入口。

### 命令与快捷键

命令描述包含稳定 ID、中文名称、分类、适用区域、执行条件与默认快捷键。菜单、状态栏、格式工具条、命令搜索和快捷键调用同一处理器。命令面板合并核心操作与已授权插件命令，标明来源。应用内快捷键页支持搜索、修改、冲突提示与恢复默认。

| 操作 | 建议默认键位 |
| --- | --- |
| 新建、打开、保存、另存 | `Ctrl/Cmd+N`、`Ctrl/Cmd+O`、`Ctrl/Cmd+S`、`Ctrl/Cmd+Shift+S` |
| 查找、查找替换 | `Ctrl/Cmd+F`。Windows/Linux 用 `Ctrl+H` 替换，macOS 用 `Cmd+Option+F`，避开系统隐藏窗口功能 |
| 粗体、斜体、链接 | `Ctrl/Cmd+B`、`Ctrl/Cmd+I`、`Ctrl/Cmd+K`，焦点在源码或可编辑预览时生效 |
| 命令面板、视图切换 | `Ctrl/Cmd+Shift+P`。视图切换先提供可搜索命令，经各平台冲突测试后分配快捷键 |
| 右键菜单和撤销 | Windows/Linux 提供 `Shift+F10`。撤销与重做沿用平台和编辑器约定 |

### 工作区文件树

顶栏「工作区」展开独立文件面板。打开文件夹由原生选择器授权，按展开节点逐层加载。核心宿主管理工作区根目录和窗口范围，文件定位、排序、过滤均基于相对路径。目录链接和 Windows junction 的目标须在允许范围内。打开已加载文件继续使用现有窗口去重机制。文件树提供路径面包屑、定位当前文件、手动刷新，后续增加外部变更监听与工作区搜索。文档大纲继续描述当前文件结构。

## 初始插件选择

| 分类 | 内容与归属 | 入口 |
| --- | --- | --- |
| 编辑核心 | CommonMark、GFM 表格与任务列表、脚注、编辑命令、查找替换、文档大纲与工作区文件树 | 随应用提供，按界面需要展开 |
| 写作与渲染 | 公式、Mermaid、额外代码语言。文件中的对应内容可提示启用该组件 | 安装器选装，设置内启停 |
| 导出 | HTML、PDF、PNG/JPG。PNG/JPG 共用安装组件，各格式可独立启停 | 安装器选装，设置内启停 |
| 视图 | 专注视图、后续演示等额外视图 | 安装器选装，设置内启停 |
| 外观 | 浅色和深色随应用提供。Midnight 可选装，本地主题使用 `.edplugin` | 安装器与「设置 → 插件」，切换入口在外观 |
| 本地命令 | P4 第三方命令，按插件版本授权和回滚 | 「设置 → 插件」安装和管理，「命令」运行 |

- **安装向导**提供「精简」「推荐」「自定义」。「精简」预选 HTML 导出。「推荐」预选现有八组，覆盖已有写作与输出能力。「自定义」按分类调整具体组件。升级时沿用用户上次的选择。旁边用一句话说明效果，例如「公式｜显示 LaTeX 行内和块级数学表达式」。
- **首次启动**按「写作与渲染」「导出」「视图」「外观」展示本次安装可用的组件。预设变更前显示受影响项目，稍后可在设置中启停。
- **插件设置**用搜索框匹配中英文功能名、别名和 ID。例如搜索「画流程图」能找到 Mermaid。筛选项显示「已启用」「已停用」「未安装」。缺少的官方 Windows 组件提供安装器指引。继续用「安装插件文件」接收主题和 P4 命令包。

维护一份官方组件目录，包含稳定 ID、分类、短说明、别名、默认选择、安装组件组和功能开关。用它生成 NSIS 选项并驱动应用内界面。沿用物理资源拆分、完整性验证及现有默认安装目录，安装与启用状态分别显示。升级迁移保持原 ID、停用设置和版本授权。[组件构建](../scripts/optional-components.mjs) · [安装选项](../src-tauri/windows/components.nsh) · [当前插件设置](../src/demo/settings.tsx)

## 分阶段交付与验收

| 阶段 | 可交付范围 | 验收条件 |
| --- | --- | --- |
| P5.1 日常编辑与兼容性 | 命令表、可搜索命令面板、快捷键默认值及冲突检查、源码 Markdown 着色、选区工具条、查找替换，修复脚注与表格对齐 | 同一格式操作从按键、菜单、命令面板得到相同源码；选区保留并支持一次撤销；中文输入法候选期间无误触发；脚注可跳转与返回；同份表格预览与 HTML、PDF、PNG/JPG 的列对齐一致 |
| P5.2 预览编辑与插件发现 | 接入段落和标题的就地编辑，增加任务勾选、表格编辑面板、公式与 Mermaid 快捷入口、分类组件选择和插件搜索 | 中文、emoji、组合字符及 BOM/CRLF 可往返；跨视图撤销一致；过期修订无法覆盖新内容；围栏和表格周围的 Markdown 保持原格式；最小／部分／标准安装状态准确，升级保留选择，跨窗口启停一致 |
| P5.3 工作区 | 先交付选择文件夹、懒加载文件树、快速按名定位和打开，再加文件菜单、外部变更刷新、跨文件搜索和链接诊断 | 同路径聚焦已有窗口；根目录外和越界链接无法读写；外部重命名与未保存草稿能正确提示；Windows 仅改大小写的重命名可用；大目录按展开节点加载 |
| 后续导出与扩展 | 可搜索文本 PDF、更多图表与代码呈现、源文档移动后的链接更新，按需评估数学编号、提示块、引用和导入插件 | 用中文、公式、长代码、脚注及多页样例对比各格式；验证 PDF 文本提取、分页、字体、链接和离线输出 |

优先采用 **P5.1 → P5.2 → P5.3**。P5.1 的命令和源文档事务可供预览编辑与文件菜单复用。P5.2 的插件目录独立于预览写回，可并行实现。真实中文输入法和 Windows 安装器交互需要实机验收。macOS 与 Linux 在发布对应安装包前分别验证按键、工作区和导出行为。[当前验收记录](VERIFICATION.zh-CN.md)

P5.1、P5.2 与 P5.3 已按上述边界实现于当前版本。验收表区分实机的选择器检查与模拟 Tauri command 的文件树用例。
